# Demo Script — StockWise Inventory System
**Version:** v1.0.0

## 1. Open the app (30 sec)
- Open [https://your-app.onrender.com](https://stockwise-inventory-4ocz.onrender.com/)
- Show the dashboard — point out KPI cards and low stock alerts

## 2. Add an item (1 min)
- Click Add Item
- Fill in: Name, Category, Quantity, Price
- Click Save — show success toast
- Go to Inventory — show the new item in the table

## 3. Adjust stock (30 sec)
- Click Stock button on any item
- Add 10 units — show quantity update

## 4. Show alerts (30 sec)
- Set an item quantity to 2
- Go to Dashboard — show it appears in Low Stock Alerts

## 5. Reports page (30 sec)
- Open Reports
- Show Total Value, Gross Margin, Stock Availability KPIs

## 6. Activity Log (30 sec)
- Open Activity Log
- Show all actions are recorded with timestamps

## 7. CI/CD pipeline (1 min)
- Open GitHub Actions — show green pipeline
- Explain: push to main → tests → smoke test → deploy

## 8. Security (30 sec)
- Show .env file (without revealing values)
- Explain: helmet, rate limiting, basic auth, input validation
