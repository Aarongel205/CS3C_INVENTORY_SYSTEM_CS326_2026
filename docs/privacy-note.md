# Privacy Note
**Project:** StockWise Inventory Management System
**Assigned:** Neil

---

## Data Collected

StockWise collects **no personal data** about end users. The only data stored is:

| Data Type | Example | Purpose |
|-----------|---------|---------|
| Item name | "Wireless Mouse" | Identify inventory item |
| SKU | "WIRE-1042" | Unique item reference |
| Category | "Electronics" | Grouping and filtering |
| Quantity | 25 | Stock level tracking |
| Price | ₱499.00 | Cost and value reporting |
| Supplier | "TechSource PH" | Procurement reference |
| Activity log entries | "Added item: Keyboard" | Audit trail |

---

## What We Do NOT Collect
- Names, emails, or contact details of users
- Location data of users
- Browser or device fingerprints
- Login credentials (no authentication system currently)
- Payment information

---

## Data Storage
- All data is stored in **Supabase** (hosted PostgreSQL in Singapore region by default)
- Activity logs are retained for operational auditing purposes
- No data is sold or shared with third parties
