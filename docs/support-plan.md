# Support Plan
**Project:** StockWise Inventory Management System
**Assigned:** Sophia

---

## Issue Reporting Process

1. User notices a bug or issue
2. User opens a **GitHub Issue** at the project repository
3. Issue must include:
   - Title: brief description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshot (if UI-related)
4. Issue is labeled (bug / enhancement / question)
5. Team lead (Sophia) triages and assigns to a team member
6. Fix is developed on a feature branch and merged via PR
7. Issue is closed when fix is deployed
